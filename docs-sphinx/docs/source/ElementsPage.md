## Базовые элементы

### Заголовок

#### Назначение
Элемент используется для добавления текстового заголовка внутри формы. Он помогает разделять форму на смысловые блоки и не требует ответа от респондента.

#### Что отображается
На холсте и при прохождении формы отображается крупный текст заголовка. Если для элемента добавлены вложения, они отображаются под заголовком.

#### Свойства
- Тип поля: отображает тип элемента "Заголовок".
- Заголовок: основной текст, который видит респондент. Максимальная длина заголовка - 120 символов.
- Только для просмотра: включает режим, при котором элемент остается информационным и не используется для ввода ответа. Иконка замка в правой верхней части свойств.
- Вложения: файлы, прикрепленные к элементу. Можно добавить до 10 файлов размером до 20 MB каждый. Если прикреплено несколько изображений, можно выбрать отображение последовательным списком или слайдером.
- Условная логика: настройка зависимости отображения элемента от ответа на другой элемент. Можно выбрать элемент-источник, условие "Равно", "Не равно" или "Дан ответ", а также ожидаемое значение для условий сравнения.

#### Поведение элемента
Респондент видит заголовок как информационный текст. Элемент не создает поле для ввода ответа и не участвует в проверке обязательных ответов.

### Текст

#### Назначение
Элемент используется для ввода произвольного текстового ответа. Он подходит для коротких ответов, комментариев и развернутых текстовых пояснений.

#### Что отображается
На холсте и при прохождении формы отображается заголовок поля, вспомогательный текст, текстовая подсказка и поле ввода. Если для элемента добавлены вложения, они отображаются под полем.

#### Свойства
- Тип поля: отображает тип элемента "Текст".
- Заголовок: основной текст вопроса или подпись поля, которую видит респондент. Максимальная длина заголовка - 120 символов.
- Текст подсказка: текст внутри поля до ввода ответа. Максимальная длина подсказки - 80 символов.
- Вспомогательный текст: пояснение под заголовком элемента. Максимальная длина вспомогательного текста - 1200 символов.
- Обязательное поле: включает требование заполнить поле перед отправкой формы.
- Многострочный текст: переключает элемент между однострочным и многострочным режимом ввода.
- Максимальная длина ответа: задает ограничение длины ответа. Для однострочного режима доступно от 1 до 255 символов, для многострочного режима - от 1 до 10000 символов.
- Только для просмотра: включает режим, при котором поле нельзя заполнить. При включении этого режима обязательность поля отключается. Иконка замка в правой верхней части свойств.
- Вложения: файлы, прикрепленные к элементу. Можно добавить до 10 файлов размером до 20 MB каждый. Если прикреплено несколько изображений, можно выбрать отображение последовательным списком или слайдером.
- Правильные ответы: список значений, которые считаются правильными при автоматической проверке.
- Баллы за правильный ответ: количество баллов, начисляемое за правильный ответ.
- Условная логика: настройка зависимости отображения элемента от ответа на другой элемент. Можно выбрать элемент-источник, условие "Равно", "Не равно" или "Дан ответ", а также ожидаемое значение для условий сравнения.

#### Поведение элемента
Респондент вводит текст в поле. В однострочном режиме ответ ограничен коротким вводом, в многострочном режиме поле позволяет вводить длинный текст. Если поле обязательное, пустой ответ не проходит проверку.

- Разрешить десятичные дроби: разрешает ввод чисел с десятичной частью.

## Элементы выбора

### Выпадающий список

#### Назначение
Элемент используется для выбора ответа из раскрывающегося списка вариантов. Он подходит для компактного выбора одного или нескольких значений.

#### Что отображается
На холсте и при прохождении формы отображается заголовок поля, вспомогательный текст и раскрывающийся список. Если для элемента добавлены вложения, они отображаются под списком.

#### Свойства
- Тип поля: отображает тип элемента "Выпадающий список". Элемент можно преобразовать в "Флажок" или "Переключатель".
- Заголовок: основной текст вопроса или подпись поля, которую видит респондент. Максимальная длина заголовка - 120 символов.
- Вспомогательный текст: пояснение под заголовком элемента. Максимальная длина вспомогательного текста - 1200 символов.
- Обязательное поле: включает требование выбрать ответ перед отправкой формы.
- Разрешить несколько ответов: позволяет выбрать несколько вариантов в одном списке.
- Включить опцию "Другое": добавляет вариант для собственного ответа респондента.
- Варианты ответов: список доступных значений. Варианты можно добавлять, изменять и удалять.
- Только для просмотра: включает режим, при котором список нельзя заполнить. При включении этого режима обязательность поля отключается.
- Вложения: файлы, прикрепленные к элементу. Можно добавить до 10 файлов размером до 20 MB каждый. Если прикреплено несколько изображений, можно выбрать отображение последовательным списком или слайдером.
- Правильные ответы: варианты, которые считаются правильными при автоматической проверке. Для одиночного выбора задается один правильный вариант, для множественного выбора можно задать несколько правильных вариантов.
- Баллы за правильный ответ: количество баллов, начисляемое за правильный ответ.
- Условная логика: настройка зависимости отображения элемента от ответа на другой элемент. Можно выбрать элемент-источник, условие "Равно", "Не равно" или "Дан ответ", а также ожидаемое значение для условий сравнения.

#### Поведение элемента
Респондент открывает список и выбирает вариант ответа. Если включен множественный выбор, можно выбрать несколько значений. Если включена опция "Другое", респондент может ввести собственный вариант.

## Расширенные элементы

### Дата и время

#### Назначение
Элемент используется для ввода даты, времени или даты и времени вместе.

#### Что отображается
На холсте и при прохождении формы отображается заголовок поля, вспомогательный текст, поле выбора даты и поле выбора времени. Если для элемента добавлены вложения, они отображаются под полями.

#### Свойства
- Тип поля: отображает тип элемента "Дата и время".

- Убрать время: скрывает поле выбора времени. Переключатель недоступен, если уже скрыто поле даты.
- Только для просмотра: включает режим, при котором дату и время нельзя выбрать.

- Условная логика: настройка зависимости отображения элемента от ответа на другой элемент. Можно выбрать элемент-источник, условие "Равно", "Не равно" или "Дан ответ", а также ожидаемое значение для условий сравнения.

#### Поведение элемента
Респондент выбирает дату через поле даты и время через поле времени. Нельзя одновременно скрыть дату и время, потому что в этом случае элемент не сможет принять ответ.

### Рейтинг

#### Назначение
Элемент используется для выбора числовой оценки по шкале.

#### Что отображается
На холсте и при прохождении формы отображается заголовок поля, вспомогательный текст и ряд кнопок с оценками от 1 до максимального значения. Если для элемента добавлены вложения, они отображаются под рейтингом.

#### Свойства
- Тип поля: отображает тип элемента "Рейтинг".

- Условная логика: настройка зависимости отображения элемента от ответа на другой элемент. Можно выбрать элемент-источник, условие "Равно", "Не равно" или "Дан ответ", а также ожидаемое значение для условий сравнения.
