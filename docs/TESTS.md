# TESTS

## Текущие тесты (актуально на 15 февраля 2026)

1. `frontend/e2e/auth.setup.ts`
   Что проверяет:
   - Сервис доступен и готов к работе.
   - Пользователь может авторизоваться.
   - Сессия после входа корректно сохраняется для остальных тестов.

2. `frontend/e2e/builder.smoke.spec.ts`
   Что проверяет:
   - Страница конструктора открывается и основные элементы интерфейса видны.
   - Работают базовые действия конструктора: предпросмотр, сохранение, публикация.
   - Работает базовое редактирование формы: изменение, добавление и удаление элемента.
   - Работают базовые действия с историей изменений (undo/redo).

Итого сейчас: setup + 7 smoke-тестов, запуск в `chromium` и `firefox`.

## Запуск локально

```bash
cd frontend
npm ci
npx playwright install
npx playwright test
```

## Политика по изменениям исходного кода ради тестов

Разрешено (нормально):
- Добавлять стабильные селекторы (`data-testid`, `data-field-id`) на динамичные и локализуемые элементы.
- Добавлять недеструктивные атрибуты, которые не влияют на бизнес-логику.

Не разрешено:
- Добавлять ветки логики "только для тестов" в рабочий код.
- Ослаблять валидации/безопасность ради прохождения e2e.
- Писать в UI/репорты секреты и пароли.

Приоритет выбора селекторов:
1. `getByRole`/`getByLabel`/`getByPlaceholder`.
2. `data-testid` для мест, где пункт 1 хрупкий (динамика, i18n, повторяющиеся элементы).
